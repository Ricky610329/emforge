# 單機與多機算法平台

本計畫依 09-08 使用者定案，取代 09-07 任務書順序及衝突定義。
指定機器由平台啟停；傳送固定版本程式碼，使用各機既有 Python 環境。
agent 驗證後可自動發布；不 push、不部署真 HFSS、不修改 Antenna 或 NAS。

## 里程碑
1. 執行與候選身分：run_id/tag、保留 Record.run、歷程與取樣。
2. 收件與 client：冪等送件、部分派工、重複候選共用結果、成本與預算。
3. HTTP 與遠端 Depot：CLI/Python/MCP 共用操作、真 socket 契約。
4. 算法執行端：程式包、指定機器/環境、行程/checkpoint、啟停/斷線。
5. 評估與 MCP：固定評估版本、多指標、效率/校準、共享取樣限制。
6. 更新與恢復：驗證、停止派工、保存/對帳/重啟、相容回退與故障證據。

每段 TDD、全套測試與 pyflakes 全綠後獨立 commit。
驗收涵蓋單機與 2 算法端/2 模擬端網路流程、中斷恢復、共用量測不灌水。
平台单一協調端，FileDepot 保留；不做自動 GPU 排程、環境安裝或破壞性資料遷移。
